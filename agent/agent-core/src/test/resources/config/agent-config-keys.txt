# Agent configuration keys: a public contract (T-API-009, O-R03, 19 §9 "config-keys.snapshot",
# docs/compatibility.md). Every PUBLIC and DIAGNOSTIC key of ConfigKeys, one line each, sorted:
#   key<TAB>type<TAB>default<TAB>remote<TAB>kind<TAB>env
# key      canonical name; set in argos-agent.yml, as the system property -Dargos.<key>, or as env
# type     KeySpec type; an enum lists its values: enum(a|b)
# default  the documented default; (none) = no default (required, unset or computed at start),
#          "" = empty
# remote   Y = remote change allowed by default, N = only when remote-config.allow names it,
#          - = never changed remotely
# kind     public or diagnostic (debug.*, honoured in release builds)
# env      the environment variable (ARGOS_ + key, . and - as _, upper case); - when none sets it
#          (a family such as ...services.*, or agent.disabled which is read only from -D).
#          ARGOS_TOKEN, ARGOS_CONFIG and the file name argos-agent.yml are fixed names outside
#          this table, pinned by the same test.
# TEST keys (argos.test.*, argos.testing.*) are development-build only and not listed.
# Checked by AgentConfigKeySnapshotTest (:agent:agent-core:test). Change this file by hand, in the
# same change as the key, add a CHANGELOG entry and report every addition, rename or change.
