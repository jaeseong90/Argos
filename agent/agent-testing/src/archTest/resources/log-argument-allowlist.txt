# LOG-01 allow-list (10 §14 "정적 검사", SEC-26; AgentCodeRules.logArgumentsAreSafe, LogAllowlist).
# The agent's INFO, WARN and ERROR log calls take constants, numbers, enums, classes, files, paths
# and throwables. A string argument needs one of the entries below:
#   producer <class>#<method or field>  <why its strings are identifiers or operator settings>
#   site <class>#<method>               <why every string logged in that method is safe>
# A new line is reviewed like code: say where the value comes from. Collected data (SQL,
# parameters, headers, URL queries, user ids) never qualifies.

# --- Identity, configuration and agent-internal identifiers --------------------------------------
producer io.argos.agent.core.export.AgentInfo#version  Implementation-Version of the agent jar manifest
producer io.argos.agent.core.export.AgentInfo#commit  Argos-Commit of the agent jar manifest
producer io.argos.agent.core.export.AgentInfo#protocolVersion  Argos-Protocol-Version of the agent jar manifest
producer io.argos.agent.core.config.AgentConfig#appName  app.name, operator configuration (10 §15)
producer io.argos.agent.core.config.AgentConfig#appEnv  app.env, operator configuration (10 §15)
producer io.argos.agent.core.config.LoadedConfig#configHash  16 hex digits of xxh3 over the configuration without the token (SEC-06)
producer io.argos.agent.core.config.TokenHolder#masked  always argos_**** (C-94)
producer io.argos.agent.core.export.Exporters#configuredName  exporter name of test.exporter (noop, drop, file, grpc)
producer io.argos.agent.instrumentation.api.InstrumentationModule#id  module id of 10 §5.1 (servlet, jdbc, ...)
producer io.argos.agent.core.boot.TransformRecorder#loaderName  bootstrap, app, platform or a class loader class name
producer io.argos.agent.core.boot.StartTimer#format  a number of milliseconds

producer io.argos.agent.core.log.AgentLogger#destination  the log file path or the stderr fallback description

producer io.argos.agent.core.boot.TransformRecorder#modules  instrumentation module ids of a transformed class
producer net.bytebuddy.description.type.TypeDescription#getName  the binary name of a class being transformed (an identifier)
producer io.argos.agent.core.guard.SelfProtection#label  an instrumentation module id or its number
