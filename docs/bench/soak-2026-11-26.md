## Method and deviations

- Stack (18 §11.2): ServerTestEnvironment (Testcontainers PostgreSQL and ClickHouse with the installation's configuration), the server boot jar as a child JVM (LoadServerJvm, 17 §7.2 options, NMT), shop-boot3 and shop-batch with the agent (gRPC over TLS to the collector, `-XX:NativeMemoryTracking=summary`, self-diagnostics file), ext-stub, and the sample-apps/load generator, all on one host.
- Deviation: the load is the sample-apps/load generator (bench mix of 18 §7.2, own Java code, p99 per run) instead of k6; one generator run per hourly point gives the hourly p99.
- Deviation: Testcontainers instead of a Compose `test` profile (the server load run's layout); the Compose profile is a follow-up proposal.
- Single host: the split load generator of ADR-0010 C-244 (6) is not built; the generator costs little at 500 requests/s (a few percent of one core) and its CPU shows in the host's load, not in the agent's measurements.
- Agent heap: `jcmd GC.run` twice, then `GC.class_histogram`, bytes of the classes whose name starts with `io.argos.` (the agent's own and relocated classes; arrays the agent owns count under their array class, so the app's whole live heap of the same histogram is listed as a reference series). NMT: committed Internal + Other + Thread of `VM.native_memory summary`. Agent threads: `argos-*` names of `Thread.print`.
- WAL: `argos_wal_bytes`. The WAL rotates segments at `argos.wal.segment-bytes` (256 MiB, 12 §3.4) and deletes only closed segments, so at 500 TPS it grows past 100 MB within about 20 minutes in normal operation; the limit of 18 §11.2 is applied as written and the conflict is left to the PM (WO-52 report).
- p99 verdict: mean of the later hourly p99 points minus the mean of the first 6 (the first half when the run has fewer than 12), against twice the baseline's sample standard deviation (at least 5% of its mean).
- Alert false positives: FIRING events of the template rules (`/alerts/templates/apply` for both apps). The bench mix has 5% intended `500` answers, which meets the `error_rate` WARN threshold of 5% by design, and the collector certificate the harness generates is valid for 2 days, which fires the server self rule on certificate expiry: such firings are listed as expected and not counted.
- Disk growth: bytes on disk of the formula's tables against `Σ rows × B` of 13 §14 (N-19), between the first and the last 10-minute sample.
- Not judged here: T-NFR-28 (virtual thread overhead, WO-51 bench); `-Psoak.vt=true` only runs the soak with virtual threads.
