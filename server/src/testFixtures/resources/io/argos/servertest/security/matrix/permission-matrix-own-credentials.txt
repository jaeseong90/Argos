# Operations whose handler itself checks a credential that the permission matrix (T-SEC-49, T-API-010)
# cannot generate. They may answer 401 or 403 to the generated request, but only from the handler:
# PermissionMatrix still requires that the request reached it. Everything else stays strict; an entry
# for an operation that no longer exists fails the run.
# Format: METHOD /path<TAB>reason
POST /api/v1/auth/login	the password of the request is wrong (14 §4.1)
POST /api/v1/auth/refresh	the request has no valid refresh cookie (14 §4.1, 14 §2.2)
POST /api/v1/setup/admin	the setup token of the request is wrong (ADR-0010 C-106 (1))
